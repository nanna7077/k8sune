# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately by email to [k8sune@nannan.in](mailto:k8sune@nannan.in).

Include a clear description, affected version, reproduction steps or proof of concept, and the potential impact when possible.

Please do not open a public GitHub issue for a suspected vulnerability. I will acknowledge the report, investigate it, and coordinate a fix and disclosure with you.

## Supported versions

Security fixes are provided for the latest released version of k8sune.
